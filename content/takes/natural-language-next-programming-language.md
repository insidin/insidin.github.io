When compilers became mainstream, software engineers stopped routinely reviewing the machine instructions they produced. We moved to higher-level programming languages, allowing us to focus on what we wanted to achieve rather than how every instruction should be executed.

AI is driving another fundamental shift in abstraction. Yet many still largely approach AI-generated software as code that humans need to read, understand and review. We're holding on to an engineering model that is already changing.

Natural language is becoming the interface through which we express intent, supported by specifications, architectural constraints, business rules and expected behavior. AI increasingly translates that intent into working implementations, which it can subsequently modify, maintain or replace. Software source code becomes less important as a human-facing artifact. The focus shifts towards defining what the system should achieve, under which conditions, and independently verifying that it does.

Of course, today's LLMs aren't compilers. Natural language introduces ambiguity, and generated implementations don't come with the same guarantees. But that's precisely why we need to evolve our engineering practices, rather than simply applying traditional code reviews to an entirely different way of producing software. So this isn't just another productivity improvement. It changes the abstraction at which we engineer software.

And with that, it challenges the role of developers, the responsibilities of architects, how we organize engineering teams, and how we establish trust in the systems we build. We should be investing in specification-driven engineering, executable architectural constraints and independent verification, rather than assuming that humans will always need to understand every line of generated code. The next generation of software engineers won't necessarily be those who write the best code, but those who can best express intent, define constraints and establish that the resulting systems behave as intended.
